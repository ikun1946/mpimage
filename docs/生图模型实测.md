## 比例遵守情况

用同一提示词追加现行比例描述，`gemini-3-pro-image` 与 `gemini-3.1-flash-image` 的结果一致：

| 要求比例 | 实际输出 | 偏差 |
| --- | --- | --- |
| 1:1 | 1024×1024 | 0% |
| 9:16 | 768×1376 | ≈0.8% |
| 21:9 | 1584×672 | ≈1.0% |
| 3:1 | 1792×592 | ≈0.9% |

极端比例（3:1、21:9）同样能按描述出图，说明提示词里的比例描述对这些模型有效。

## 代码相关

- 网关只把对话模型列在 `/v1/models` 里，生图模型不在列表，因此控制台用「常用清单 + 自定义 ID」。
- 部分上游只返回 `data[0].url`，`server/src/app/products/images/magpie.ts` 已补上下载分支（上限 40MB）。
- Gemini 系列返回 JPEG，`detectImageType` 已支持。
